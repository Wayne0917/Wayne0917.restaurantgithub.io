# 🍽️ 專案名稱：餐廳形象網站（Restaurant Website）

## 🧩 專案介紹
這是一個以 **HTML5、CSS3、JavaScript** 製作的餐廳主題網站，模擬實際餐飲品牌的線上形象頁面。  
主要呈現餐廳介紹、菜單內容、聯絡資訊等，透過 RWD 響應式設計讓使用者在不同裝置上皆能有良好體驗。

---

## 🎯 專案目標
- 熟悉網頁結構與語意化標籤
- 強化排版與 CSS 動畫效果
- 練習網站導覽設計與版面配置
- 建立具備 RWD 響應式的完整前端作品

---

## 🧠 開發重點
- 採用 **模組化結構思維**，將區塊劃分為獨立區域（導覽列 / 主內容 / 頁尾）
- 使用 **Flexbox / Grid** 進行版面布局
- 應用 **Media Query** 實現手機、平板、桌機版本響應式設計
- 增加 **互動動畫（hover、scroll）** 提升使用體驗

---

## 💡 功能特色
- 🍜 主頁導覽導入平滑捲動效果
- 📱 響應式設計支援多裝置顯示
- 🧾 菜單頁面以卡片式設計呈現餐點內容
- 📍 聯絡表單模擬顧客留言功能
- 🎨 自訂配色與字型強化品牌感
